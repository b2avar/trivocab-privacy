## App Store "App Privacy" beyanı (özet)

Kullanım verisi yalnızca kullanıcı ilk açılıştaki soruya izin verirse toplanır (Unity Gaming Services). Beyan, Unity Analytics paketinin Apple'a gönderdiği gizlilik manifestosuyla uyumludur. 1.0.10 (Trivocab Plus) ile satın alma doğrulaması için RevenueCat eklendi; bu, izin sorusundan bağımsız çalışır (Plus erişimi için gerekli).

| Kategori › Tür | Toplanıyor mu | Kullanıcıya bağlı mı | İzleme (tracking) | Amaç |
|---|---|---|---|---|
| Identifiers › User ID (Unity kurulum kimliği; RevenueCat anonim kullanıcı kimliği) | Evet | Evet | Hayır | Analytics, App Functionality |
| Identifiers › Device ID (IDFV) | Evet | Evet | Hayır | Analytics |
| Location › Coarse Location (IP'den ülke/şehir) | Evet | Evet | Hayır | Analytics |
| Usage Data › Product Interaction | Evet | Evet | Hayır | Analytics |
| Diagnostics › Crash Data, Performance Data, Other Diagnostic Data | Evet | Evet | Hayır | Analytics, App Functionality |
| Purchases › Purchase History (RevenueCat) | Evet | Evet | Hayır | App Functionality |
| Contact Info, Financial Info (kart bilgisi), Precise Location, User Content, Advertising Data | Hayır | – | – | – |

## Google Play "Veri güvenliği" (1.0.10 eki)

- Finansal bilgiler › Satın alma geçmişi: toplanıyor, paylaşılmıyor (RevenueCat hizmet sağlayıcıdır), zorunlu, amaç: Uygulama işlevleri.
- Uygulama etkinliği / Uygulama bilgileri ve performans / Cihaz kimlikleri: önceki beyan aynen (Unity, isteğe bağlı).
- Ödeme bilgisi (kart) toplanmaz; Google Play alır.
